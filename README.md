# Setlist Maker

rekordbox のプレイリストエクスポート (txt) から、SNS 投稿用のセトリ画像を生成する Web アプリ。

**Demo:** https://syokenn334.github.io/setlist-maker/

## 主な機能

### アートワーク自動取得

rekordbox のトラック情報 (アーティスト名・曲名) をもとに、iTunes Search API からアルバムアートワークを取得する。アーティストが一致し、リミックス表記などの括弧内も一致したものを正しいジャケットとして使い、括弧内だけが違う場合は原曲などのジャケットを代用する。代用したジャケットはプレビューにだけ破線の枠を表示し、書き出す画像には出さない。iTunes Search API の呼び出し制限 (約 20 回/分) に合わせて 3 秒間隔で検索する。

### セトリ画像生成

- **サイズ** — 16:9 (1600x900、書き出しは 2 倍)・4:5 (1080x1350)・1:1 (1080x1080)・3:4 (1080x1440)
- **1 列 / 2 列** — 16:9 のみ 2 列を選べる
- **1 列 10 曲** — 曲数が多い場合は自動でページを分ける。前から詰め、2 列のときは左の列から埋める。文字とジャケットの大きさは 10 行が入る大きさで決まり、ページの曲数が少なくても変わらない
- **セーフマージン** — 放送の action safe (各軸 3.5%) の内側に揃えて配置する (1:1 は左右に Instagram の一覧で欠ける分を足す)
- **5MB を超えるページ** — 写真の背景などで PNG が X の上限 (5MB) を超えるページだけ JPEG で書き出す

### カスタマイズ

- **メタ情報** — イベント名・DJ 名・日付
- **テーマ** — Dark / Light / Mono / Midnight / Warm
- **背景画像** — 拡大 (最小は画像で全面を覆う大きさ)・位置・彩度・明るさ・ぼかし・オーバーレイを専用の画面で調整
- **曲の非表示・ジャケットの手動選択** — プレビューの曲または曲一覧から操作

### YouTube プレイリストと QR コード

利用者自身の Google Cloud の OAuth クライアント ID と API キーで Google にログインし、セトリの曲を YouTube で検索してプレイリストを作成する。作成したプレイリストの QR コードを最後のページ (または全ページ) に載せられる。クライアント ID・API キー・アクセストークンはメモリ上にだけ保持し、ブラウザのストレージには保存しない。

### PNG 書き出し

modern-screenshot でブラウザ内で PNG を生成する。ZIP でまとめて保存・1 枚ずつ保存・共有 (Web Share API に対応した端末) を選べる。フォント (Inter / Noto Sans JP) は @fontsource で同梱している。

## 使い方

1. rekordbox からプレイリストを txt エクスポート
2. ファイルをドラッグ＆ドロップ (または「ファイルを選ぶ」)
3. アートワークが自動取得される
4. サイドバーでメタ情報・レイアウト、「背景・スタイル」で背景とテーマを調整
5. 「Export」で画像を出力

## 技術スタック

- React 19 + TypeScript
- Vite
- modern-screenshot (PNG 書き出し)
- fflate (ZIP)、qrcode (QR コード)
- iTunes Search API (アートワーク取得)
- Google Identity Services + YouTube Data API v3 (プレイリスト作成)

## 開発用ツール

- `npm run samples`: `samples/` に架空の曲名で作った検証用 txt を生成する
- `npm run matrix:update`: 全組み合わせ (サンプル x アスペクト比 x カラム数 x テーマ x 状態) の PNG を書き出し、基準画像として `.matrix/baseline/` に保存する
- `npm run matrix`: 同じ組み合わせを `.matrix/current/` に書き出し、基準画像との差分を `.matrix/diff/` に出力する。`npm run matrix -- 16x9` のように指定すると、ID に文字列を含むケースだけを対象にする

一覧は開発サーバーの `/setlist-maker/dev/matrix.html` でも確認できる。初回は `npx playwright install chromium` が必要。

## 更新履歴

### v1.0.0
- UI と生成画像を全面的に作り直し (UI は Radix Colors を基にしたダークテーマ、生成画像はセーフマージンとグリッドに沿った配置)
- サイズを 16:9 / 4:5 / 1:1 / 3:4 に変更 (7:8・9:16 を廃止)
- 背景・スタイルの編集画面、曲一覧、YouTube プレイリスト作成と QR コード、ZIP・共有での書き出しを追加
- PNG 書き出しを html2canvas から modern-screenshot に変更し、フォントを同梱
- ロゴ機能を廃止

### v0.6.0
- **ロゴ追加 (テスト機能)**: サイドバーの「ロゴ」セクションから PNG / JPEG / SVG をアップロード可能。スライダーで高さを 20〜100% で調整
  - 配置はリスト最下行に揃える。16:9 は 2 列目中央、7:8 / 9:16 は中央寄せ
  - ロゴと重なる曲は次ページに移動。1 列 + 16:9 のみ重なる行を半分幅に縮小して同ページに残す
  - ※ 実運用で当て込みながら調整が必要なテスト機能のため、サイズ・位置・アスペクト比別の挙動は今後変更される可能性あり

### v0.5.0
- **曲の非表示機能**: プレビュー上で曲をクリック/タップしてメニューから「非表示」を選択
  - ジャケットは半透明の灰色プレースホルダーに置換 (中央に italic の `ID` ラベル)
  - タイトル / アーティスト / アルバム / BPM / 時間 / ジャンルは同色の矩形でマスク
- **ジャケット手動差替**: 同じメニューから「ジャケット検索」で候補から選択
- **サイドバー UI 整理**: 「背景」セクションを「テーマ」と「背景」に分割。スライダーに「透過率」「1列の最大表示曲数」ラベルを追加
- **PNG エクスポート時のジャンル文字の縦位置ズレを修正** (`line-height` で高さ揃え)

### v0.4.0
- スマートフォン対応 (レスポンシブ): 768px 以下で上下分割レイアウトに自動切替
  - 上部 45vh にプレビュー固定、下部にスクロール可能な操作 UI
  - 出力画像の解像度は変更なし (プレビュー表示のスケーリングのみ)

### v0.3.0
- 7:8 アスペクト比追加 (Twitter 画像2枚投稿向け 1050x1200)
